# 学科预设档案

八类预设的分值配比与命题侧重。改配比时同步改 `scripts/init_exam.py` 的 `PRESETS`。

---

## engineering — 工科·机电类

**配比** 填空 15(15空) / 单选 20(10题) / 判断 10(10题) / 简答 20(4题) / 计算 25(3题) / 设计 10(1题)

**适合** 机械设计、机电传动、电气控制、液压、车辆、材料力学、理论力学

**命题侧重**
- 计算题：电机参数、传动比、强度校核、受力分析。数据凑整，分步设问
- 设计题：继电器-接触器控制、液压回路、机构方案。必须给全工艺条件
- 判断题最容易变成"背多分"，要用"超过临界值反而减小"这类反直觉点

**答案写法**：公式 → 代入 → 结果，三步分开给分。设计题按"主电路/控制逻辑/保护"分档。

## science — 理科·数学/物理/信号

**配比** 填空 20(10空) / 单选 16(8题) / 计算 44(4题) / 证明 20(2题)

**适合** 高等数学、线性代数、概率统计、大学物理、电路分析、信号与系统

**命题侧重**
- 计算题占 44%，是拉开差距的主力。每题 11 分，通常 2–3 小问
- 证明题必须有"求证"环节，考中值定理、收敛性、线性相关性
- 填空考公式的记忆精度（系数、符号、条件），不考推导

**答案写法**：关键步骤单独占行并标分；"显然""易得"一律不许出现在答案里。

**坑**：符号体系要统一（$j$ 还是 $i$、$\omega$ 还是 $f$），三套卷不能混用。

## cs — 计算机

**配比** 单选 30(15题) / 填空 10(10空) / 简答 20(4题) / 程序阅读 15(3题) / 算法设计 25(1题)

**适合** 数据结构、操作系统、计算机网络、数据库、编译原理

**命题侧重**
- 程序阅读：给可运行代码问输出 + 时间复杂度。代码 ≤ 25 行
- 算法设计：给函数签名 + 约束（数据规模 10^5、要求 O(n log n)），按"思路/边界/代码"三段给分
- 简答考"为什么"（为什么用 B+ 树不用红黑树），不考"是什么"

**答案写法**：算法题先给思路（3–5 行），再给代码，最后给复杂度分析。缺复杂度分析扣 3 分。

## humanities — 人文社科

**配比** 名解 20(4题) / 简答 32(4题) / 论述 30(2题) / 材料分析 18(1题)

**适合** 马原、毛概、思修、近代史、文学、教育学、社会学

**命题侧重**
- 名解 40–80 字，抓"定义 + 要素 + 作用"
- 论述题必须带**结合点**（"结合自身实际""结合中国式现代化"），否则是背书题
- 材料题的材料 200–400 字，设问与材料逐条对应，防背模板

**答案写法**：按"观点—论证—结论"分层，每层单独标分。要点用教材原话，不自行发挥。

**坑**：论述题答案容易写成讲义，控制在 400–600 字，给分点 6–8 个即可。

## law — 法学

**配比** 单选 30(15题) / 判断 10(10题) / 简答 18(3题) / 法条分析 22(2题) / 案例分析 20(1题)

**命题侧重**
- 法条分析给条文原文，问构成要件 + 法律后果 + 条文间关系
- 案例题材料 150–300 字，问"是否构成/应如何处理"，必须能落到具体条文
- 判断题考"但书"和例外情形（"一律""均"多为错项）

**答案写法**：**结论 → 法律依据（条号 + 条文）→ 理由**。
只写结论不写依据不得分；结论错则依据与理由部分不计分。

## medical — 医学

**配比** 单选 20(20题,5选项) / 多选 20(10题,5选项) / 名解 16(4题) / 简答 24(4题) / 病例分析 20(1题)

**命题侧重**
- 多选是重灾区：错选、少选、多选均不得分，卷面必须写明
- 名解考严格定义（"心力衰竭""休克"），不能用口语描述
- 病例分析：主诉 + 查体 + 辅助检查，问诊断、依据、鉴别、处理

**答案写法**：病例题按"诊断—诊断依据—鉴别诊断—处理原则"四段给分，诊断错则该题不超 1/3 分。

**坑**：单选题干不能给"提示性"描述（"最可能的诊断是"配一堆典型症状），否则秒选。

## language — 语言

**配比** 单选 20(20题) / 完形 10(10空) / 阅读 20(4题) / 翻译 20(2题) / 写作 30(1题)

**命题侧重**
- 客观题靠题量，考词汇辨析、语法点、固定搭配
- 阅读理解每篇 2 小问（细节 + 主旨），材料 200–300 词
- 写作必须给字数下限和分值构成（内容/结构/语言），否则无法按比例扣分

**答案写法**：翻译按"忠实 50% + 通顺 50%"；写作给参考范文 + 分档标准。

## business — 经管

**配比** 单选 30(15题) / 判断 10(10题) / 简答 20(4题) / 计算 20(2题) / 案例 20(1题)

**适合** 微观/宏观经济学、管理学、会计学、财务管理、市场营销

**命题侧重**
- 计算题：弹性、均衡价格、成本利润、财务比率、NPV。数据要能算出漂亮结果
- 案例：给企业经营情境，问"用什么理论分析"，按"理论—分析—结论"给分
- 判断题考"前提条件"（"其他条件不变时…"）

**答案写法**：计算题写公式 + 过程 + 结论；案例题先点明理论，再套材料，最后给建议。

## 自定义配比

预设不合适时，三种改法（从轻到重）：

1. `--scores 20,20,10,20,20,10` — 只改分值，题数按单价自动重算
2. 改 `init_exam.py` 的 `PRESETS` 里 `plan` 列表 — 改题型、题数、答题区高度
3. 直接改生成的 `paper_A.tex` — 加题型、加小题，但之后要自己核分值

**约束**：大题数必须是 4、5 或 6（得分表列数固定），分值合计必须是 100。
