# 题型写法与陷阱

每类给三样：**好的长什么样、常见的坏题、LaTeX 片段**。

---

## 填空（fill）

考"精确记忆"：术语、公式、数值范围、符号含义。**不能考推理**。

- 好：`他励直流电动机的机械特性可写成 $n=n_0-\beta T$，其中 $\beta$ 称为机械特性的____。`
- 坏：`直流电机调速方法有____。`（答案不唯一，无法判分）

**规则**：一空一答；答案 ≤ 8 字；空宽按答案长度给 1.2–2.8cm；一道题最多 2 空。

```latex
\xiaoti{5. 三相笼型异步电动机的降压启动方法主要有 Y-$\Delta$ 降压启动、\kong[2.6cm]降压启动和定子串电阻启动。}
```

---

## 单选（choice）

题干必须是**一个完整判断**，选项与题干能连读成句。

- 好：`直流电动机要实现恒功率调速，应改变（　）`
- 坏：`关于直流电机，下列说法正确的是（　）`（四个选项各说一件事，靠背）

**四选项、答案唯一、干扰项同层级**（同类术语，不能三项明显荒谬）。
医学类常五选项（A–E），用 `opts=5`。

```latex
\xiaoti{4. 直流电动机要实现恒功率调速，应改变（\hspace{1.2cm}）\\
A. 电枢电压 $U$\qquad B. 励磁磁通 $\Phi$\qquad C. 电枢回路电阻 $R_a$\qquad D. 负载转矩}
```

---

## 多选（multi）

医学、法学常用。**错选不得分，少选按比例给分**（卷面必须写明规则）。
选项 5 个（A–E），正确答案 2–3 个。

---

## 判断（tf）

一句一个判断，**不留模糊地带**。

- 好：`热继电器既可用作电动机的过载保护，也可用作短路保护。`
- 坏：`热继电器的保护效果较好。`（"较好"无法判）

绝对化词（"一定""都""完全"）是天然的错项；但别每题都用，否则学生摸规律。

---

## 名词解释（term）

答案 40–80 字，结构固定：**定义 + 关键要素 + 一句作用/特点**。

评分：定义 3 分 + 要素 2 分。同义表述不扣分，"只写举例不写定义"扣半。

---

## 简答（short）

问"是什么/为什么/有哪些"，答案 4–6 个要点，**每点可独立给分**。

- 好：`为什么说实践是认识的基础？`
- 坏：`谈谈你对实践的理解。`（开放题不该占简答位）

答题区 5–8cm。

---

## 论述（essay）

要求"原理 + 展开 + 结合"。设问必须包含**结合点**，否则学生只背不写。

- 好：`试述量变与质变的辩证关系原理，并说明这一原理对个人学习与成长的指导意义。`
- 坏：`试述量变与质变。`（背书题，区分度为 0）

答题区 12–14cm。评分按"观点—论证—结论"分层。

---

## 计算（calc）

分步设问，标注每问分值，前问结论供后问使用。

```latex
\begin{ti}
\xiaoti{1.（8 分）一台他励直流电动机，$P_N=22$ kW，$U_N=220$ V，$I_N=116$ A，$n_N=1500$ r/min，
$R_a=0.18\ \Omega$。试求：\\
（1）额定转矩 $T_N$；\quad（2）额定反电动势 $E_{aN}$；\quad（3）直接启动电流及其倍数。}
\kongbai{12cm}
\end{ti}
```

**数据自检**：`$T_N = 9.55 P_N/n_N$` 这类公式先自己算一遍，结果不合理就改条件。

---

## 证明（prove）

数学/物理类。必须给全"已知、求证"，缺"求证"按不规范扣分。

```latex
\xiaoti{2.（10 分）已知 $f(x)$ 在 $[a,b]$ 上连续、在 $(a,b)$ 内可导，且 $f(a)=f(b)$，求证：存在 $\xi\in(a,b)$ 使 $f'(\xi)=0$。}
```

---

## 程序阅读（code_read）

给 15–30 行可运行代码，问输出 + 复杂度。代码用 `code` 环境（等宽、自动缩进对齐）。

```latex
\begin{code}
int f(int n) {
    if (n <= 1) return 1;
    return n * f(n - 1);
}
\end{code}
```

**坑**：代码里不能出现未转义的 `%`（LaTeX 注释符）、`_`（下标）、`&`。用 `code` 环境可避开部分问题，但 `%` 仍需写成 `\%`。

---

## 算法设计（code_write）

给函数签名 + 约束（数据规模、时空复杂度），答题区留足 14cm。

- 好：`设计算法判断单链表是否有环，要求空间复杂度 O(1)，说明思路并给出代码。`
- 坏：`写一个排序算法。`（无法按点给分）

---

## 设计（design）

工科核心大题。给完整工艺/功能条件，要求画图 + 说明。

- 必须给全约束：动作顺序、保护要求、控制方式、允许的元件
- 答题区 15cm 以上，允许跨页时用 `\kongbai` 分两段
- 评分按"主电路 / 控制逻辑 / 保护环节 / 元件说明"分档

---

## 案例（case）

法学、医学、经管。材料 150–300 字，设 2–3 小问，**逐问给分**。

结构模板：
```latex
\xiaoti{1.（20 分）（案例材料…）\\
请回答：（1）…；（2）…；（3）…。}
```
评分按学科范式：
- 法学：结论 → 法律依据 → 理由（结论错则后两项不计分）
- 医学：诊断 → 依据 → 鉴别 → 处理（诊断错则该题不超 1/3 分）
- 经管：理论 → 分析 → 结论

---

## 材料分析（material）

人文社科。材料 200–400 字，设问必须**与材料逐条对应**，防止背模板。

- 好：`（1）运用社会存在与社会意识辩证关系的原理，分析该县脱贫实践。`
- 坏：`结合材料谈谈你的看法。`

---

## 法条分析（law）

给出条文原文，问构成要件与适用后果。

```latex
\xiaoti{1.（11 分）《民法典》第五百七十七条：当事人一方不履行合同义务或者履行合同义务不符合约定的，
应当承担继续履行、采取补救措施或者赔偿损失等违约责任。\\
请分析：（1）本条规定的违约责任构成要件；（2）三种救济方式之间的关系。}
```

---

## 阅读理解（reading）

语言类。材料 200–300 词，每篇 2 小问（细节 + 主旨）。答题区按需 6–8cm。

---

## 翻译（translate）

给出待译段落，注明评分侧重（忠实 50% + 通顺 50%）。答题区 7cm。

---

## 写作（writing）

给题目/话题 + 字数下限 + 分值构成（内容/结构/语言）。答题区 18cm 以上。

**卷面必须印字数要求**，否则无法按比例扣分。
