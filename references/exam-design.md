# 命题方法论

## 1. 先做双向细目表，再写题

不列这张表就动笔，三套卷必然头重脚轻。表格自己留着，不用给用户看。

```
章节 | 知识点             | 认知层次 | A卷 | B卷 | C卷 | 合计
-----|-------------------|---------|-----|-----|-----|-----
第1章 | 系统运动方程式      | 应用     |  8  |  5  |  0  | 13
第1章 | 折算转动惯量        | 综合     |  0  |  8  | 10  | 18
第2章 | 直流电机机械特性    | 理解     | 10  |  6  |  8  | 24
...
```

**认知层次**按四级分：
- 识记：名词、公式、参数含义 → 填空、选择、判断、名解
- 理解：原理、机理、条件 → 简答、判断、选择
- 应用：套公式解题、标准流程 → 计算、计算、作图
- 综合：多知识点联动、设计、分析 → 论述、案例、设计

**分配原则**：识记∶理解∶应用∶综合 ≈ 25∶25∶30∶20（工科）；文科调成 35∶30∶20∶15。

**覆盖检查**：每个章节至少被某个大题覆盖一次；标注"重点章"（老师划的）的覆盖率要 100%，
非重点章允许只出 1–2 道客观题。三套卷合起来，全课程无死角。

## 2. 难度不是标签，是行为

别写"本卷较难"，要让难度体现在题上：

| 手法 | 简单 | 中等 | 难 |
|---|---|---|---|
| 条件给法 | 参数齐全、直接代入 | 需先求中间量 | 条件隐含、需自己识别 |
| 设问 | 一问一答 | 分步设问 | 开放/比较/设计 |
| 干扰项 | 明显错误 | 概念混淆 | 貌似正确但边界条件不成立 |
| 计算量 | 一步到位 | 2–3 步 | 需分情况讨论 |

**A/B/C 的实际做法**：
- A 卷：题干直给数据，设问（1）（2）递进但每步独立
- B 卷：加一个"需先求某中间量"的条件，或把两章知识拼在一题
- C 卷：条件含一个陷阱（如"忽略铁损"），或要求讨论"若 X 变化，结论如何变"

## 3. 三套卷防撞题

**允许**：同一考点换角度。
- A：他励直流电机弱磁调速属于什么调速方式？（选择）
- B：为什么弱磁调速只能在额定转速以上进行？（简答）
- C：弱磁调速时若负载为恒功率负载，电枢电流如何变化？说明理由。（分析）

**禁止**：改个数字、换个主语就算新题。
- ✗ A：一台 22kW 电机求额定转矩；B：一台 30kW 电机求额定转矩
- ✓ 换成"求启动电阻"或"求调速范围"

查重阈值 0.82（字符 bigram 相似度），`check_exam.py` 会自动报。

## 4. 干扰项怎么造（选择题）

四个选项的错误要有**不同类型的错**，不能三个都是瞎编：
1. 正确项
2. **相近概念替换**（把"启动转矩"换成"最大转矩"）
3. **条件缺失**（结论成立但前提不成立，如"串电阻越大启动转矩越大"——超过临界值反而减小）
4. **方向/符号反了**（"升高"与"降低"、"正比"与"反比"）

判断题的坑同理：用"一定""都""总是"埋绝对化陷阱，用"约""主要"埋范围陷阱。
**但不要埋语义歧义**——判不了真假的题是坏题。

## 5. 计算题设计规范

- **分步设问**，前问结论供后问用，便于按步给分：`（1）求 X；（2）用 X 求 Y；（3）讨论 Z`
- **数据要"好看"**：结果落在整数或两位小数，避免 137.4826 这种
- **自己先算一遍**：算不出整数就调条件，不要硬凑
- **量纲写明**：`$T_N$（N·m）`、`$n$（r/min）`
- 允许用计算器的课程，数字不必刻意凑整，但答案要给出中间步骤

## 6. 答案册的给分结构

| 题型 | 给分点拆法 |
|---|---|
| 填空 | 每空 1 分，含义正确即可，同义表述不扣分 |
| 单选 | 2 分，不倒扣 |
| 判断 | 1 分，不倒扣 |
| 名解 | 定义 3 分 + 要素/作用 2 分 |
| 简答 | 按要点，每点 1–3 分，答出关键术语即给分 |
| 计算 | 公式 1–2 + 代入 1–2 + 结果 1–2，过程缺失扣半 |
| 论述 | 观点 4 + 论证 8 + 结论 3，层次清晰可上浮 1–2 |
| 案例 | 按设问逐问给分，结论错则依据与理由不计分 |
| 设计 | 按完整性、逻辑正确性、保护环节分档 |

**写评分标准时用小字灰楷**（`\pingfen{}`），印出来像教研室标注，学生也不会误读成答案内容。

## 7. 交付前自检

- [ ] 三套卷分值都是 100，得分表与各题声明一致
- [ ] 每个大题的分值 = 题数 × 每题分（填空还要核空数）
- [ ] 三套卷无重复题干（跑 check）
- [ ] 每题答案能对上，选择题答案在选项范围内
- [ ] 计算题自己算过，结果落在合理量级
- [ ] 没有"（题干）""（选项）"残留
- [ ] PDF 编译三遍，页眉"共 N 页"是实数
- [ ] 翻一遍 PDF，没有跨页撕裂的大题表格
